# One-Must-Act

**The venture-framing skill: 0 → 1 → 100.**

One-Must-Act turns any product, platform, or business plan into a disciplined game
plan: define the **100** (definite goal + exit math), audit the **0** (measured
reality), specify the **1** (checkable working-platform criteria across five gates —
nothing multiplies until all check), sequence multipliers **2–99** on purpose, and run
a monthly scorecard.

> *You cannot multiply a fraction. 0.99 × anything is still less than whole.*

## 🚀 Quick Start

### Install

```bash
# Download the skill
git clone https://github.com/diamitani/one-must-act-skill.git ~/.hermes/skills/one-must-act
```

### Use

Say **"one must act"** — or hand it any venture, product, or platform plan — and get a
complete game-plan doc: the equation, the 100, the audited 0, the 1-checklist, the
work from 0 to 1, the multipliers, the math, the scorecard, and this week's actions.

---

## 📐 The frame

| Stage | Meaning |
| --- | --- |
| **0** | Where we are today — measured, not imagined |
| **1** | A working platform that can scale — whole and complete |
| **2–99** | The multipliers: partners, customers, team, investors, vendors |
| **100** | The definite goal |

The **1** is earned across five gates: **A.** it works · **B.** it takes money
correctly · **C.** it's safe · **D.** it can be watched and fixed · **E.** it proves
people want it. All verified **on production**.

## 🔗 Integrations

- **pop** (Project Output Planner) — bidirectional handoff: one-must-act frames the
  plan, POP generates the full execution package (Master Doc, Build Guide, Execution
  Handoff). See `references/pop-handoff.md`.
- **Jev ecosystem** (advisory): `jev-backend-qa` for the 0-audit health check,
  `jev-skill-select` for multiplier/tool choice, `jev-memory` for research filtering,
  `jev-compaction` for long handoffs, `jev-model-routing` for cost control.
