# Scorecard Template — monthly update ritual

The scorecard is the plan's heartbeat. Update it on the **first of every month**.
If it stops updating, the plan is dead.

| Date | Stage (0 / 1 / multiplying) | Customers | Paying | ARR | Week-1 activation | Week-4 retention | Team size | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| YYYY-MM-01 |  |  |  |  |  |  |  |  |

## Update ritual (5 minutes)

1. Fill one new row. Copy last month's row first, then change what moved.
2. If any box in the 1-checklist changed state, say which and why.
3. If a multiplier was added (2–99), name it and the date — it only counts if the 1
   was already reached (or the multiplier is explicitly needed to reach the 1).
4. One line in Notes: the single most important thing learned this month.

## Stage rules

- **0** — any box in the 1-checklist is unchecked.
- **1** — all boxes checked, no multipliers added yet.
- **multiplying** — 1 reached, multipliers being added on purpose.
